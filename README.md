# Cybersecurity Incident Response Playbook

## Introduction

This project provides a practical cybersecurity incident response playbook that will guide one on how to respond to security incidents. This includes the various phases of incident response such as preparation, detection, containment, eradication, recovery, and post-incident actions.

In this case, the selected incident scenario is based on phishing.

## Objectives

- Acquire basic knowledge on cybersecurity incident response.
- Acquire basic knowledge on the different phases of incident response cycle.
- Acquire basic knowledge on a phishing-based account compromise.
- Acquire knowledge on incident triage and severity.
- Acquire knowledge on containment and eradication actions.
- Acquire knowledge on evidence collection and preservation.
- Acquire knowledge on communication and escalation.
- Create an incident response checklist.
- Acquire knowledge on post-incident analysis.

## Incident Scenario

The scenario selected involves an employee who receives a phishing email having a malicious link that directs the employee to a fake login page. Upon logging in, the employee uses his/her credentials and the unauthorized person is able to log into the account.

The playbook provides ways in which the incident can be detected, investigated, contained, eradicated, and recovered from.

## Phases of Incident Response Lifecycle

The incident response playbook consists of the following phases:

1. Preparation
2. Detection and Identification
3. Triage
4. Containment
5. Eradication
6. Recovery
7. Lessons Learned

## Important Topics Covered

- Detection and identification of incidents
- Triage and prioritization of incidents
- Containment and isolation of accounts
- Eradication and securing credentials
- Evidence gathering and retention
- Communication and escalation
- Incident response checklist
- Incident response severity matrix
- Root cause analysis
- Lessons learned
- Incident response roles and responsibilities
